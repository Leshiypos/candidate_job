# 005. Проверка и подготовка сдачи

Статус: blocked
Зависимости: 004.

## Цель

Подготовить воспроизводимый комплект без секретов, лишних файлов и недостоверных заявлений.

## Работа

- Выполнить процедуру из `docs/DELIVERY.md` на точном наборе передаваемых файлов.
- Проверить наличие программы, инструкции, решений, записки и подлинных полных экспортов использованных ИИ-сессий. По уточнению пользователя полный экспорт Codex подходит для сдачи (D-003).
- Непроверенные экспорты хранить в `private/`; ключи и пароли удалить из сдаваемых копий согласно условию.
- Указать инструмент и состав приложенных записей, проверить полноту и зафиксировать оставшиеся ограничения.
- Подготовить комплект в `dist/` по разрешённому списку; ничего не отправлять без поручения пользователя.
- В случае передачи репозитория проверить всю передаваемую историю на секреты.

## Критерии приёмки

- [x] Полный набор тестов успешно выполнен после подготовки комплекта с доступными экспортами.
- [x] Из отдельной распакованной копии комплекта проходят тесты и запуск на 2026-11-10.
- [x] Проверены точный список и содержимое вошедших файлов и экспортов; секретов не обнаружено. Комплект собран без истории Git.
- [ ] Все обязательные материалы присутствуют; ограничения честно описаны.
- [x] Проверки записаны без раскрытия секретов; выполненные этапы имеют согласованные статусы.

При отсутствии обязательного транскрипта или неразрешённой находке безопасности задача не может получить статус `done`.

## Проверки после задания

По `docs/DELIVERY.md` проверить состав и содержимое комплекта, затем из его отдельной копии выполнить `python3 -m unittest discover -s tests -v` и команду отчёта из README. Сверить результаты с этапом 004. Записать использованные способы поиска секретов, охват, результат и ограничения; автоматическое сканирование не заменяет просмотр экспорта сессий.

- Оба экспорта просмотрены целиком. Повторный поиск по шаблонам ключей, токенов, паролей, заголовков авторизации и URL с учётными данными совпадений не обнаружил. SHA-256 каждого файла сверена с байтами, просмотренными ранее. Обе копии в ZIP совпадают с экспортами побайтно.
- Одноразовый локальный сборщик в режиме `--review` принял явные пары имён и SHA-256 двух экспортов, проверил список 31 файла, CRC и совпадение всех файлов с распакованной копией. `python -m unittest discover -s tests -v` прошёл все 44 теста в проекте и после распаковки. Команда из README заново сформировала отчёт на 2026-11-10, который побайтно совпал с образцом.
