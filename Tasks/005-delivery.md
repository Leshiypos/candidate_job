# 005. Проверка и подготовка сдачи

Статус: todo
Зависимости: 004.

## Цель

Подготовить воспроизводимый комплект без секретов, лишних файлов и недостоверных заявлений.

## Работа

- Выполнить процедуру из `docs/DELIVERY.md` на точном наборе передаваемых файлов.
- Проверить наличие программы, инструкции, решений, записки и настоящих экспортов Claude Code для всех использованных сессий.
- Непроверенные экспорты хранить в `private/`; ключи и пароли удалить из сдаваемых копий согласно условию.
- Если экспорта Claude Code нет, явно записать невыполненное требование. Экспорт Codex не является его заменой.
- Подготовить комплект в `dist/` по разрешённому списку; ничего не отправлять без поручения пользователя.
- В случае передачи репозитория проверить всю передаваемую историю на секреты.

## Критерии приёмки

- [ ] Полный набор тестов успешно выполнен после подготовки комплекта.
- [ ] Из отдельной распакованной копии проходят тесты и запуск на 2026-11-10.
- [ ] Проверены точный список и содержимое файлов, экспортов и передаваемой истории; секретов не обнаружено.
- [ ] Все обязательные материалы присутствуют; ограничения честно описаны.
- [ ] Проверки записаны без раскрытия секретов; выполненные этапы имеют согласованные статусы.

При отсутствии обязательного транскрипта или неразрешённой находке безопасности задача не может получить статус `done`.

## Проверки после задания

По `docs/DELIVERY.md` проверить состав и содержимое комплекта, затем из его отдельной копии выполнить `python3 -m unittest discover -s tests -v` и команду отчёта из README. Сверить результаты с этапом 004. Записать использованные способы поиска секретов, охват, результат и ограничения; автоматическое сканирование не заменяет просмотр экспорта сессий.
