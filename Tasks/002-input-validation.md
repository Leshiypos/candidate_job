# 002. Чтение и проверка данных

Статус: done
Зависимости: 001.

## Цель

Надёжно прочитать CSV в типизированные структуры и объяснять ошибки входа.

## Работа

- Создать `advance_report/`, модели и чтение CSV стандартной библиотекой.
- Читать деньги точно из строк, даты — как календарные даты.
- Проверять заголовки, обязательные поля, дубли ID, ссылки, принадлежность работы договору, допустимые статусы и согласованность дат.
- Определить обработку пустых, отрицательных, нечисловых, бесконечных сумм и лишних дробных знаков. Записать решения.
- Сообщать имя файла, строку и поле ошибки без избыточных дампов содержимого.

## Критерии приёмки

- [x] Исходные CSV читаются без изменения: 2 договора, 9 работ, 8 платежей.
- [x] Некорректные данные отклоняются понятной ошибкой.
- [x] Денежные значения нигде не преобразуются через float.
- [x] Тесты загрузки и валидации успешно пройдены после задания.
- [x] Документация обновлена, изменённые файлы проверены на секреты.

## Проверки после задания

Создать тесты `unittest`: корректный ввод, CSV с кавычками и запятыми, отсутствующий файл/столбец, повторный ID, неизвестная ссылка, работа чужого договора, неверная дата/статус, недопустимая сумма, точное чтение копеек. Использовать временные файлы и синтетические данные.

Команда: `python3 -m unittest discover -s tests -v`. Записать фактическое число тестов и результат.

## Результат и проверки

Добавлены неизменяемые модели и `load_data(data_dir: Path) -> ReportData`. Суммы представлены целыми копейками, даты — `date`. Правила проверки записаны в [D-011](../DECISIONS.md). Загрузчик останавливается на первой ошибке. Для ошибки записи диагностика сообщает файл, начальную физическую строку и поле. Для ошибок доступа и кодировки указывается файл.

- `python -m unittest discover -s tests -v` на Python 3.11.9 в Windows: прошёл 21 тест. На этом компьютере `python3` указывает на недоступный псевдоним Windows. Тесты проверяют также UTF-8 с BOM, многострочные кавычки, плохой CSV, историческую приёмку и совпадение дат оплаты и возврата.
- Независимый вызов загрузчика через `python -X utf8 -B -` подтвердил 2 договора, 9 работ и 8 платежей, целые копейки и сумму первого договора. `git diff --exit-code HEAD -- data` подтвердил неизменность CSV.
- Вручную проверены имена, читаемость функций, аннотации типов, docstring публичного API, повторное использование валидаторов и комментарий о сохранении истории. Скриптом Python проверены длины строк и отсутствие литералов `float`. Ввод суммы проверен от текста до `int`.
- Проверены локальные Markdown-ссылки, статусы, `git diff --check` и шаблоны ключей, токенов, паролей, заголовков авторизации и URL с учётными данными в изменённых файлах. Совпадений с шаблонами нет.
