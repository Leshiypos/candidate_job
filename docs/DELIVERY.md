# Подготовка приватной сдачи

## Разрешённый состав

Собирать комплект из явно выбранных файлов, а не командой архивирования всей рабочей папки:

- `README.md`, `AGENTS.md`, `Roadmap.md`, `DECISIONS.md`, `ACCOUNTANT_NOTE.md`, `.gitignore`;
- исходные `data/FORMAT.md`, `data/contracts.csv`, `data/works.csv`, `data/payments.csv`;
- исходники `advance_report/*.py` и тесты `tests/` без кешей и временных файлов;
- документация `Tasks/*.md` и `docs/*.md`;
- проверенные подлинные записи использованных ИИ-сессий с указанием инструмента; в комплекте поместить в `transcripts/`. README требует экспорт Claude Code; допустимый формат для стороннего ИИ необходимо установить перед сдачей (D-003);
- при необходимости — проверенный пример отчёта с явной датой.

Некоторые перечисленные материалы будут созданы на следующих этапах. Их отсутствие сейчас не означает, что комплект готов.

Не включать `.git/` в архив, `.env*`, ключи и сертификаты, локальные конфигурации инструментов, виртуальные окружения, кеши, непроверенные транскрипты, `private/`, чужие файлы или предыдущие архивы. Проверять символьные ссылки и не включать ссылки на файлы вне разрешённого состава. Каталог `dist/` служит местом сборки, его содержимое не копируется рекурсивно внутрь самого себя.

## Проверка перед сдачей

1. Сверить критерии этапов 001–004 и обязательные материалы из README.
2. Собрать отдельный каталог в `dist/` по списку выше и вывести только имена включённых файлов для проверки состава.
3. Проверить все передаваемые тексты на приватные ключи, токены, пароли, строки подключения с учётными данными, заголовки авторизации и URL с секретами. Использовать доступный локальный сканер секретов или поиск шаблонов с выводом только имён файлов (`rg -l`), затем ручной просмотр. Не отправлять файлы во внешние сервисы проверки. Само слово «пароль» в правилах не является секретом; отсутствие совпадений не гарантирует безопасность.
4. Каждый транскрипт просмотреть целиком: секрет может находиться в аргументах команды, выводе инструмента, вставленном тексте или приложении. Удалять ключи и пароли из сдаваемой копии; не подменять полную сессию пересказом. Наличие других конфиденциальных данных, которые нельзя передать и нельзя удалить по условию, зафиксировать как препятствие сдаче.
5. Если передаётся репозиторий, проверить также все передаваемые коммиты и ветки: удаление файла из текущего дерева не удаляет его из истории. `.gitignore` этого не решает. Не переписывать существующую историю без согласованного действия.
6. При находке не печатать секрет в чат или журнал. Указать путь и тип, очистить комплект, при необходимости уведомить владельца о замене раскрытого секрета и повторить проверку.
7. Создать архив, проверить его перечень файлов и распаковать в отдельный временный каталог. Запустить там тесты и команду из README на 2026-11-10. Убедиться, что результат не зависит от файлов вне комплекта.
8. Записать в задаче 005 проверенные пути, команды/процедуру, результаты тестов и проверки секретов, ограничения. Передавать только проверенный вариант; любое последующее изменение требует повторной проверки затронутых материалов.

Текущее состояние: комплект сдачи не создан, программа и тесты отсутствуют. Подготовка документации выполнена в Codex. По уточнению пользователя работодатель разрешил сторонний ИИ, поэтому использование Codex допустимо. Открытым остаётся формат сдачи его сессий с учётом требования README об экспорте Claude Code; это не препятствует разработке.
