# Журнал решений

Для каждого нового решения: что решали, варианты, выбор и причина, что изменится при ошибке выбора. Расчётные допущения должны быть понятны бухгалтеру и иметь ссылку на задачу.

## D-001. Способ запуска

- Что решали: минимальная архитектура программы.
- Варианты: Python CLI, TypeScript CLI, маленький HTTP-сервис.
- Выбрано: локальный Python CLI на стандартной библиотеке. Для трёх CSV достаточно файлового ввода; сеть, установка сторонних пакетов и секреты не нужны.
- Если выбор неверен: поменяются способ запуска и упаковка; согласованные расчётные правила сохранятся.
- Состояние: принято как направление реализации; кода пока нет.

## D-002. Ведение документации и проверок

- Что решали: как вести поэтапную работу и подтверждать завершение.
- Варианты: единый список в README или отдельные задачи с общим реестром.
- Выбрано: `Tasks/` с реестром, критериями приёмки и записью проверок после каждого задания; [Roadmap.md](Roadmap.md) используется для обзора этапов, текущего состояния и следующего шага. Статусы синхронизируются с файлами задач. Исходный README сохраняется, решения ведутся здесь.
- Если выбор неверен: изменится организация документов, результат расчёта не изменится.
- Состояние: принято по запросу пользователя.

## D-003. Использование стороннего ИИ

- Что решали: допустима ли работа в Codex при упоминании Claude Code в README.
- Источник: пользователь уточнил 2026-11-25, что в тексте работодателя разрешено использование стороннего ИИ.
- Варианты: считать Claude Code единственным разрешённым инструментом или учитывать дополнительное разрешение работодателя.
- Выбрано: учитывать уточнение пользователя; использование Codex разрешено и не является ограничением разработки.
- Если трактовка неверна: потребуется согласовать способ работы и подтверждающие материалы; расчётные правила от выбора ИИ не зависят.
- Открытый вопрос: разрешение стороннего ИИ само по себе не определяет замену требуемого README экспорта Claude Code. Не заявлять соответствие формату сдачи без основания; сохранять подлинные записи с указанием инструмента.
- Состояние: разрешение принято, формат сдачи сессий стороннего ИИ не установлен.
